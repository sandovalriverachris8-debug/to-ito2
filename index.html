Preguntas frecuentes

Aquí encontrarás respuestas a las dudas más comunes sobre CSS, los temas del curso y las herramientas que utilizarás para diseñar sitios web.

¿Qué es CSS?

CSS (Cascading Style Sheets, u hojas de estilo en cascada) es el lenguaje que define la apariencia de una página web. Permite controlar colores, fuentes, márgenes, tamaños, distribución y adaptación a diferentes dispositivos. Se utiliza junto con HTML, que organiza el contenido.

¿Qué aprenderé en este curso?

Aprenderás a dar estilo a textos e imágenes, manejar el modelo de caja, posicionar elementos, construir diseños con Flexbox y Grid, crear animaciones y adaptar la página a móviles, tabletas y computadoras. Los ejercicios te ayudarán a aplicar cada tema.

¿Qué es CSS GRID?

CSS Grid es un sistema de diseño que permite organizar elementos en filas y columnas. Es especialmente útil para crear estructuras de página, galerías y distribuciones complejas de forma ordenada y adaptable.
